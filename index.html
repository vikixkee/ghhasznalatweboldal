Mi az a GitHub?

A GitHub egy online platform, ahol projekteket tárolhatsz, követheted a kód változásait, és más fejlesztőkkel dolgozhatsz együtt.

📁 Repository

A repository, vagyis tároló a projekted fájljait, dokumentációját és változástörténetét tartalmazza.

🤝 Együttműködés

Megoszthatod a munkádat másokkal, módosításokat javasolhatsz, és közösen fejleszthettek projekteket.

💻 Kódkezelés

A Git segítségével rögzítheted a változtatásokat, a GitHubon pedig online kezelheted a projektedet.

GitHub lépésről lépésre

Kövesd ezt a négy lépést, és készítsd el az első projektedet!

1

Regisztrálj a GitHubra

Nyisd meg a GitHub weboldalát, hozz létre egy fiókot, majd jelentkezz be.

GitHub megnyitása ↗
2

Hozz létre egy repositoryt

Kattints a New repository lehetőségre. Adj neki nevet, például elso-projektem, és hozz létre egy új tárolót.

3

Töltsd fel a fájljaidat

Add hozzá a HTML-, CSS- és képfájljaidat. A webes felületen a fájlok feltöltésére is van lehetőség.

4

Mentsd el a módosításokat

A Commit changes művelettel rögzítheted a változtatásokat. Írhatsz melléjük egy rövid leírást is arról, mit módosítottál.

// Néhány hasznos Git-parancs 

git init
git add .
git commit -m "Elso projekt"
git branch -M main
git push

Ezek a parancsok helyi Git-projekt kezelésére szolgálnak. A git push előtt általában a távoli repositoryt is be kell állítani.

🌐 Tedd közzé a saját weboldaladat!

A GitHub Pages segítségével egy egyszerű, statikus weboldalt online is elérhetővé tehetsz. Hozz létre egy repositoryt, töltsd fel az index.html fájlt, majd a Settings → Pages részen állítsd be a közzétételt.
